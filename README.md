# Lookhep — ห้องทดลองลูกเห็บ 3D

[เปิดห้องทดลองออนไลน์](https://netzpj-max.github.io/Lookhep/) · [ซอร์สโค้ดบน GitHub](https://github.com/netzpj-max/Lookhep)

สร้างสรรค์โดย [Net Phonlakit](https://www.facebook.com/netzj)

แบบจำลองภาษาไทยจากภาพ “กระบวนการเกิดลูกเห็บ” ของมิตรเอิร์ธ · mitrearth พร้อมรายละเอียด 6 ขั้น การเล่น/หยุด ความเร็ว 0.25–8 เท่า ไทม์ไลน์ การเล่นวนวงจร กล้องหมุน/ซูม ชั้นบรรยากาศ และภาพผ่าดูชั้นน้ำแข็ง

## กราฟิกปริมาตรและ RTX

- เมฆใช้ density texture สามมิติและ ray marching พร้อมการดูดกลืนแสงและเงาภายใน แทนการเรียงทรงกลม สร้างความหนาแน่นครั้งเดียวใน Web Worker
- น้ำแข็งใช้พื้นผิวโค้งที่ขรุขระ ดัชนีหักเห 1.31 ผิวสะท้อน แกนขุ่น ฟองอากาศ และรอยแตก
- พื้นภูมิประเทศโค้ง พืช เงานุ่ม แอ่งน้ำสะท้อน และฝนที่ตกถึงพื้น
- มีมุมมองสมจริง/ดูในเมฆ และกล้องระยะใกล้ติดตามลูกเห็บ
- คุณภาพสมดุล/สูง/Ultra เปลี่ยนจำนวน sample เมฆ (48/88/144), sample แสง (3/5/8), ฝน (600/1600/3200), เพดานความละเอียดและ bloom จริง
- ตรวจชื่ออะแดปเตอร์ที่เบราว์เซอร์ใช้: RTX 4060–4090/5060–5090 เริ่มที่ Ultra; มือถือและ software renderer เริ่มที่สมดุล การเลือกคุณภาพถูกบันทึกไว้บนเครื่อง
- หยุดจำลองแล้วใช้ภาพที่วาดไว้ ไม่มีการวาด 3D ซ้ำจนกว่าจะหมุนกล้องหรือเปลี่ยนค่า ฝน เมฆ และฟ้าแลบใช้เวลาจำลองเดียวกัน จึงหยุดพร้อมกัน
- ตัวเลข FPS เป็นอัตราการวาดเฟรมที่วัดขณะทำงาน ไม่ใช่ค่าการันตี ใช้ WebGL2; VRAM ไม่จำเป็นต้องใช้เต็ม 12 GB

ทดสอบเบราว์เซอร์ทั่วไป: `npm.cmd run test:browser`

ทดสอบการเร่งด้วย GPU บน Windows:

```powershell
$env:LOOKHEP_HARDWARE = '1'
$env:LOOKHEP_TEST_URL = 'http://127.0.0.1:4173'
npm.cmd run test:browser
```

ให้เปิด preview ที่ port 4173 ก่อน การทดสอบพิมพ์ชื่ออะแดปเตอร์ที่ใช้จริง ไม่อนุมานจาก GPU ที่ติดตั้งในเครื่อง

## GitHub Pages

เมื่อ push ไปยัง `main` GitHub Actions จะทดสอบ สร้างเว็บ และเผยแพร่ไปยัง Pages อัตโนมัติ โดยกำหนดเส้นทาง `/Lookhep/` ให้ไฟล์ทั้งหมด ในเครื่องสามารถตั้ง `VITE_BASE_PATH=/Lookhep/` เพื่อทดสอบเส้นทางเดียวกับเว็บจริง

## เปิดใช้งาน

```powershell
npm.cmd install
npm.cmd run dev
```

เปิด URL ที่แสดงในหน้าต่างคำสั่ง (ปกติ http://127.0.0.1:5173) ต้องใช้เบราว์เซอร์ที่รองรับ WebGL

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

## การใช้งาน

- เล่น/หยุดด้วยปุ่มกลาง หรือ Space เมื่อไม่ได้โฟกัสตัวควบคุม
- คลิกขั้นตอนหรือจุดบนไทม์ไลน์เพื่อหยุดและสำรวจ หรือเลื่อนเวลาเอง
- เลือกความเร็ว 0.25×–8× และเปิด/ปิดการวนวงจร
- ลากหมุน เลื่อนล้อเมาส์เพื่อซูม หรือใช้สองนิ้วบนหน้าจอสัมผัส
- เปิด “ผ่าดูชั้นน้ำแข็ง” เพื่อแสดงโครงสร้างขยายหลังเริ่มเกิดแกน
- ปรับลม น้ำเหลว และรอบหมุนเวียน เพื่อดูผลในแบบจำลอง
- เปิด “เจาะลึกขั้นตอนนี้” เพื่ออ่านกลไกและ “ข้อมูลและที่มา” เพื่อดูหลักฐานกับภาพต้นฉบับ

## ขอบเขตของแบบจำลอง

เป็นแบบจำลองเชิงอธิบาย ไม่ใช่การคำนวณไมโครฟิสิกส์หรือพยากรณ์พายุ เวลาและขนาดเป็นตัวอย่าง การปรับลมกับน้ำเปลี่ยนระยะเวลาหมุนเวียนและขนาดผ่านความสัมพันธ์เชิงสาธิต ก้อนในฉากถูกขยายเพื่อให้มองเห็น อุณหภูมิใช้โปรไฟล์ตัวอย่างอิงช่วงในภาพ ไม่ใช่ข้อมูลวัดจริง

เส้นทางวนขึ้นลงใช้เพื่ออธิบายภาพต้นฉบับ ลูกเห็บจริงไม่จำเป็นต้องวนหลายรอบ และจำนวนชั้นไม่เท่ากับจำนวนรอบ ข้อความในภาพเกี่ยวกับชั้นใส/ขุ่นได้รับการแก้ไข: dry growth แข็งเร็วและกักอากาศ ทำให้ขุ่น; wet growth แข็งช้ากว่าและปล่อยอากาศ ทำให้ใส ตัวอย่างกำหนดการละลายระหว่างตกไว้ 8% เพื่อสาธิต ไม่ใช่สมการการละลาย
